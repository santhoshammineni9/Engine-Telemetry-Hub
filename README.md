# 🚗 Engine Telemetry Hub

An intelligent engine health monitoring and predictive maintenance platform that analyzes engine telemetry, identifies potential failures, and provides AI-powered diagnostic recommendations.

## ✨ Features

- Engine health monitoring using sensor parameters.
- Predictive analysis using Logistic Regression.
- Engine deterioration modeling using Markov Chains.
- Mean Time to Failure (MTTF) estimation.
- AI-powered diagnostics using Google Gemini.
- Intelligent maintenance recommendations.

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS
- **Backend:** Node.js, Express.js
- **AI:** Google Gemini API
- **Analytics:** Logistic Regression, Markov Chains
- **Tools:** Vite, Three.js

## ⚙️ Installation

```bash
git clone https://github.com/santhoshammineni9/Engine-Telemetry-Hub.git
cd Engine-Telemetry-Hub
npm install
```

Create a `.env` file:

```env
GEMINI_API_KEY=your_api_key
```

Start the application:

```bash
npm run dev
```
